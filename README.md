## 📖 Description

This project is a modern and responsive **Landing Page** designed for a tech brand (NovaTech).
It showcases a clean UI with a hero section, navigation bar, and footer.

---

## 🚀 Features

* Fully responsive design (mobile, tablet, desktop)
* Modern and clean UI
* Navigation bar (Home, Features, Contact)
* Hero section with headline and description
* Image integration for better visual appeal

---

* CSS3
* JavaScript
